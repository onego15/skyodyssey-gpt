PILOT'S FIELD GUIDE

風を読む、空を旅する。

W / Sスロットルを上げる / 下げる

↓ / ↑機首を上げる / 下げる

← / → または A / D左 / 右にバンクして旋回

SPACE車輪ブレーキ（地上）

C / Mカメラ切替 / 地図の拡大

R / H / ESC最寄りの出発地点へ / 操作 / 一時停止

離陸：Wで出力を上げ、95 km/h以上で↓を押します。
着陸：滑走路に沿って進入。出力を25〜40%にし、
80〜200 km/h、降下率7 m/s以内、水平姿勢で接地。
接地後はSで出力を下げ、SPACEで停止します。
